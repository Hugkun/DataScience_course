# 📊 Hugkun Data Science Course

このリポジトリは、Hugkunイベントの「データサイエンスコース」で使用する教材とNotebookをまとめたものです。

**ゴール**: Data Scienceの基礎を固めながら、分野への関心を高めること

## コース概要
- **時間配分**：各回1時間  
- **回数**：全3回  

## 各回の内容
- **第1回**：初めてのLLM・LLMの基礎  
- **第2回**：機械学習入門・回帰の基礎
- **第3回**：NN入門・ニューラルネットワークの基礎

## 🚀 レポジトリの内容
- コンセプト説明用資料（slides）
- 演習用のJupyter Notebook
- サンプルコードと解説
